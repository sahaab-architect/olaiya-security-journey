# LinkedIn Editions

This folder contains the LinkedIn versions of published journal episodes.

Each post provides a complete lesson and links to the full public episode
for readers who want more detail.

## Publishing format

Use the same episode number as the corresponding GitHub story.

Filename format: episode-001.md

## Post index

The first LinkedIn edition will be added with the opening episode.

## Publishing process

Posts are copied to LinkedIn manually after review.
Adding a file here does not publish it to LinkedIn automatically.
