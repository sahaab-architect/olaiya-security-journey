# Supporting Evidence

Selected screenshots and files that support published episodes.

## Evidence standard

Each item should:

- Relate to a published episode
- Show a clear result or relevant step
- Include enough context to understand it
- Have sensitive information removed
- Support only the claims it actually demonstrates

Organise evidence in subfolders using the related episode number.

Screenshots show the state captured at that moment.
Where a claim involves repeatability, the episode should explain
the additional checks performed.
